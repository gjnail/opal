Commands

opal help lists these too. Most of the tools also have short aliases from the core plugin.

Setup

CommandWhat it does
opal setupAdds opal to the startup file of every shell it finds. --dry-run shows what would change, --remove takes opal out again, and naming shells (opal setup zsh) limits it to those.
opal init SHELLPrints the startup code for zsh, bash, fish or pwsh. This is what the startup files run.
opal doctorShows the system, shell, terminal, color support and clipboard opal detected, which features and plugins are active, and PowerShell aliases that clash with plugins.
opal updateDownloads the latest release and replaces the running program, after checking it against SHA256SUMS.txt. A copy built from a clone rebuilds from that clone instead; --release forces a download.
opal greetShows the banner that new terminals open with.
opal terminalOpens Opal Terminal, which the install scripts install next to opal, in the current folder. Its own flags pass through: -profile NAME picks the shell, -dir PATH another folder, and a command after them runs instead of a shell.
opal config editOpens the config file in $VISUAL, $EDITOR, or Notepad or nano.

Themes and plugins

CommandWhat it does
opal theme listLists the themes.
opal theme preview [NAME]Shows themes as each shell would draw them. --html and --svg write them for web pages.
opal theme set NAMESwitches theme.
opal plugin listLists plugins and whether each is active.
opal plugin enable|disable NAMETurns a plugin on or off.
opal plugin install REPOInstalls a plugin from git. See Plugins.

History and folders

CommandWhat it does
opal historyOpens the history search (the same as Ctrl+R).
opal history list [N]Prints the last N commands.
opal history importImports the PowerShell, bash, zsh and fish history files again.
opal jump listLists remembered folders, best match first. opal jump add DIR and opal jump remove DIR change the list.

Tools

CommandAliasWhat it does
opal open PATHopenOpens a file, folder or URL with the default app. In WSL it opens it in Windows.
opal clip copy [TEXT]clipcopyCopies text or standard input to the clipboard. Over SSH it uses OSC 52, so the text reaches the clipboard of the computer you're sitting at, if your terminal supports it.
opal clip pasteclippastePrints the clipboard.
opal extract FILExUnpacks zip, tar, tar.gz and tar.bz2 itself, and hands xz, zst, 7z and rar to tar, 7-Zip or unrar. An archive with one top-level folder becomes that folder; anything else goes into a new folder named after the archive. A single compressed file, such as log.gz, is decompressed next to it. Existing files are never overwritten.
opal ports [PORT]portsLists listening TCP ports with the process behind each.
opal pathpathsPrints PATH one folder per line, marking missing and duplicate entries.
opal pkg VERB [NAMES]pkgRuns the system package manager. See the pkg plugin.
opal js VERB [ARGS]jsi, jsr...Runs npm, pnpm, yarn or bun, picked from the project's lockfile.
opal venv create [DIR]mkvenvCreates a Python virtualenv with this system's Python 3.
