One shell setup for zsh, bash, fish and PowerShell

opal gives every shell you use the same prompt, aliases, tab completion, suggestions and command history, from one config file, on Windows, macOS and Linux.

What it sets up

The same features in every shell, from the same config.

All shells

Prompt

Three themes with git status, command duration, exit codes, virtualenvs and SSH or root markers. The prompt symbol's color tells you which shell you're in.
All shells

Aliases and plugins

Git aliases and other plugins, written once and translated into each shell's own syntax.
All shells

Tab completion

Git branches, remotes and changed files, even in PowerShell, which has none of its own. Completions from docker, kubectl, gh and other tools are set up too.
fish · PowerShell · zsh · bash with ble.sh

Suggestions

Grey text completes what you're typing from your history. Press Tab or the Right arrow to take it.
All shells

Shared history

Every command from every shell goes into one history. Ctrl+R searches all of it, or just this folder or this shell.
All shells

Tools

j to jump between folders, open, clipboard, extract, ports, and pkg install for whatever package manager you have.

Written for each shell

opal is a single program. When a shell starts, opal init prints code written for that shell, so nothing is emulated.

  • Aliases become fish abbreviations and PowerShell functions that pass on arguments and pipeline input.
  • PowerShell's own aliases, like gc and gl, are kept unless you choose otherwise.
  • Works with bash 3.2 on macOS as well as bash 5, and with Windows PowerShell 5.1 as well as PowerShell 7.
  • The prompt never runs text from folder or branch names.
  • Setup only edits a marked block in your startup files and keeps a backup.
Get started 
# the git plugin's "gst" in each shell

# zsh and bash
alias -- gst='git status'

# fish
abbr -a -g -- gst 'git status'

# PowerShell
function global:gst {
    if ($MyInvocation.ExpectingInput) { $input | git status @args }
    else { git status @args }
}

Runs on

CI loads opal into each of these shells on every change.

Windows

Windows PowerShell 5.1, PowerShell 7, Git Bash, and any shell in WSL.

macOS

zsh, the bash 3.2 that ships with macOS, newer bash, fish and PowerShell 7.

Linux

bash, zsh, fish and PowerShell 7, on x86_64 and ARM64.

Try it in a minute

One command installs opal and sets up every shell it finds. opal setup --remove takes it out again.
